
# Elvara Beauty

A luxury salon booking and management web application.

## About

Elvara Beauty is a beauty salon platform designed to provide customers
with a seamless booking experience while allowing salon administrators
to manage appointments and monitor business activity.

## Features

### Customer
- Responsive homepage
- Service catalogue
- Service category filtering
- Specialist profiles
- Appointment booking
- Booking reference generation
- Appointment lookup
- Appointment cancellation

### Administration
- Booking statistics
- Appointment management
- Booking status updates
- Revenue overview
- CSV booking export

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Google Fonts

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Explore the application in your browser.

You can also open index.html directly in a browser.

## Demo Information

This version uses browser LocalStorage for demonstration purposes.

Bookings are stored locally and are not shared across different devices
or browsers.

The admin dashboard is a demonstration interface, not a secured
production administrator account.
